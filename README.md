Web page del apartamento Arenaysal en Conil.

### How To Use

- Clone this repo
- run `yarn`
- `yarn dev`

### How To Deploy

#### GitHub pages

Merge changes to main, GH pages is setup to autodeploy

#### Netlify

- Login into netlify with github
- after login select the forked repo or the repo you want to deploy
- after selecting netlify will automatially deploy your website.

### Tech Stack Used - 
- Next.js
- TailwindCSS
